# V0.2.1 — Per-key Rapid Trigger, named profiles and polish

## New

- **Continuous Rapid Trigger** switch on Feel, and **per-key Rapid Trigger and Continuous** overrides, for example on for WASD and off for Escape.
- **Keyboard:** actuation shown in millimetres, Shift- or Command-click to select several keys, WASD, Arrows and Modifiers group buttons, a press-point badge on changed keys, and **Clear overrides**.
- **Profiles:** names (also shown in the menu-bar menu), summary cards, **Copy settings to** another profile, **Reset**, and SOCD pairs in exports.
- **Open at Login** starts Zenblade quietly in the menu bar. The menu-bar menu adds **Mute or Unmute Microphone** and **Start Meeting Setup**.
- **Automatic switching:** add an app from the list of running apps.
- **Lighting:** the preview animates at the selected speed, and colours can be typed as hex or picked from presets.
- **Advanced and System:** pick keys on a keyboard drawing for remapping and status indicators; the assignment list is grouped.
- **Typing Test** shows words per minute, average key hold time and double presses.

## Fixed

- The bottom key row lines up with the rest of the keyboard.
- The macro recorder keeps modifiers held, so Command-C replays as a shortcut, and records function and navigation keys. A counter shows the 4,000-byte macro storage, and saving past it is prevented.
- Brightness and other lighting values no longer drift down after each read.
- A command the keyboard rejects now fails immediately instead of waiting for a timeout.
- Macros load faster, and status checks pause while the window is hidden or nothing uses them.

## Install

Installed copies of V0.2 update from inside the app (Zenblade → Check for Updates…). For a new install, download `Zenblade-0.2.1-arm64.dmg`, open it, and drag Zenblade to Applications. Requires Apple silicon and macOS 12 or newer.

The app is ad-hoc signed, without an Apple Developer ID certificate or Apple notarization. If macOS blocks it, try to open it, then use System Settings → Privacy & Security → Open Anyway and confirm Open.

To verify the download, place the `.dmg` and `.sha256` file in the same folder and run:

```bash
shasum -a 256 -c Zenblade-0.2.1-arm64.dmg.sha256
```
