# V0.2 — Rebuilt in Rust and Tauri

Zenblade is now a native Rust app built with Tauri. It looks and works the same, connects to the same keyboard settings, and keeps your profiles, while using far less disk space and memory.

## In this release

- **About 24× smaller:** the app is 12 MB instead of 285 MB. It uses the WebKit already built into macOS instead of bundling Chromium.
- **About 40% less memory:** 102 MB total footprint instead of 176 MB, measured on the same Mac with the keyboard connected.
- **Lower idle CPU**, with event-driven keyboard hot-plug detection instead of polling.
- **In-app updates:** Zenblade checks GitHub for new versions and offers to install them (Zenblade → Check for Updates…). Updates are signature-checked before they are installed.
- **New app icon** built for the macOS Liquid Glass appearances (Default, Dark, Clear and Tinted), sized to Apple's icon grid.
- Your V0.1 profiles are imported automatically on first launch.
- Microphone mute now uses the device's hardware mute where available instead of always lowering the input volume.

## Download and install

Download `Zenblade-0.2.0-arm64.dmg`, open it, and drag Zenblade to Applications, replacing V0.1. Requires Apple silicon and macOS 12 or newer.

The app is ad-hoc signed, without an Apple Developer ID certificate or Apple notarization. If macOS blocks it, try to open it, then use System Settings → Privacy & Security → Open Anyway and confirm Open. Future updates install from inside the app.

To verify the download, place the `.dmg` and `.sha256` file in the same folder and run:

```bash
shasum -a 256 -c Zenblade-0.2.0-arm64.dmg.sha256
```

## Limits

- Independent community software, not an official Pwnage release.
