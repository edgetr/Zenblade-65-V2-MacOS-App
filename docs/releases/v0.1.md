# V0.1 — First public DMG release

Zenblade brings lighting, actuation, Rapid Trigger, profiles, and onboard keyboard controls to macOS for the Pwnage Zenblade 65 V2.

## In this release

- A cleaner interface with concise headings and less repeated text.
- Connection and active profile information shared across every page.
- Expandable advanced editors, meeting setup, and status previews.
- A vector keycap icon assembled in Icon Composer, with native Liquid Glass appearances and a legacy fallback.
- Updated screenshots and a shorter getting-started README.
- A scripted DMG build with a checksum and clean ad-hoc signing.
- Renderer sandboxing, validated IPC senders, restricted device permissions, and updated build dependencies.
- An explicit macOS 12 deployment target for the native audio helper.

## Download and install

Download `Zenblade-0.1.0-arm64.dmg`, open it, and drag Zenblade to Applications. This build requires Apple silicon and targets macOS 12 or newer. Intel Macs are not included.

The app is ad-hoc signed, without an Apple Developer ID certificate or Apple notarization. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway after trying to launch it, then confirm Open. On macOS 12 this is in System Preferences → Security & Privacy.

To verify the downloaded file, place the `.dmg` and `.sha256` file in the same folder and run:

```bash
shasum -a 256 -c Zenblade-0.1.0-arm64.dmg.sha256
```

## Limits

- Independent community software, not an official Pwnage release.
- Status colors appear in the app preview; they do not drive physical per-key RGB.
- The V2’s 8,000 Hz USB interval is reported, not changed.
- This release was checked on the maintainer’s current Mac. Older macOS versions and physical keyboard writes were not revalidated for this UI release.
- Package version is `0.1.0`; earlier source-only snapshots used internal `1.x` versions. Saved-profile formats are unchanged.

- 55 automated model, protocol, and security tests passed.
- Packaged app checked at two window sizes across all six pages.
- Real keyboard detection and profile reading verified through a USB hub.
- Sandboxed preload, IPC rejection, and blocked navigation checked in the packaged app.
- DMG integrity and bundled code signatures verified; dependency audit reported zero known vulnerabilities at release time.
